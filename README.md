# PyQGIS

PyQGIS is the fundamental Python API for QGIS. It is a Python module that can be used to create custom applications and plugins for QGIS. It is also used by the QGIS application itself.

## Python

In order to use **PyQGIS API** directly in your IDE, please refer to `launch.json` file in `.vscode` folder to set up your python environment. You should replace QGIS's version with your installation.
